# Гастроманьяки — неофициальный дизайн-концепт

Самостоятельная концепция сайта гастрономических событий. Не официальный сайт и не действующая система бронирования. Реальный сайт команды: https://gastromaniacs.ru/ .

Статический HTML/CSS/JS. Запуск: `python3 -m http.server 8791`.

На широком экране три сцены связаны нативным scroll-driven CSS. На небольшом экране, при reduced motion и без поддержки animation-timeline используется вертикальная подача. Клавиатурная навигация по форматам: стрелки, Home и End. Форма создаёт редактируемый черновик, затем предлагает открыть письмо в почтовом приложении; ничего автоматически не отправляется.

Фотографии и исходный логотип получены с официального сайта Гастроманьяков. Адреса источников встроены в метаданные изображений. Фотография приготовления блюда иллюстрирует работу кухни и не заявлена как документальный кадр конкретного ужина. Никаких сгенерированных фотографий. Референс композиционного подхода: https://www.mugaritz.com/ ; его изображения и код не использованы.
